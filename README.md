# 📚 Semicolon Library

세미콜론 동아리에서 진행하는 **용산구 도서관 프로젝트** 저장소입니다.

## 프로젝트 소개

용산구 도서관을 이용하는 주민들이 도서관 정보를 더 쉽고 편리하게 찾을 수 있도록 돕는 것을 목표로 합니다.

## 주요 기능

- 용산구 내 도서관 위치 및 운영 시간 안내
- 도서 검색 및 대출 가능 여부 확인
- 도서관 행사 및 프로그램 소개

## 시작하기

```bash
git clone https://github.com/joryugallery/semicolon_library.git
cd semicolon_library
```

## 협업 규칙

- 작업 전 최신 내용을 먼저 받아오기 (`git pull`)
- 커밋 메시지는 변경 내용을 알 수 있게 작성하기 (예: `도서 검색 화면 추가`)
- 큰 파일(영상, 압축 파일 등)은 올리지 않기
